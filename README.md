## 👋 About Me

I build **cross-platform mobile apps**, **full-stack web platforms**, and **AI-powered products** — from shared-logic mobile architecture to deployed web apps with real backends.

- 📱 **Mobile** — Flutter / Dart and Kotlin Multiplatform (Jetpack Compose + SwiftUI)
- 🌐 **Web** — Next.js, React, TypeScript, Tailwind CSS
- 🤖 **AI integration** — LLM-powered features via Groq (Llama 3.3) and the Grok (xAI) API
- 🗄️ **Backend** — Supabase (PostgreSQL, Auth, RLS), Stripe payments
